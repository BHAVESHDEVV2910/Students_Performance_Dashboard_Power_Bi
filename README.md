## 📊 Project Overview

The **Student Performance Dashboard** is an interactive **Power BI data analytics project** designed to analyze and visualize student academic performance, attendance, behavior, and profile information.

The dashboard transforms student-related data into meaningful visual insights using **KPIs, charts, tables, slicers, and interactive filters**.

This project demonstrates how Power BI can be used to monitor student performance and support data-driven educational analysis.

---

## 🎯 Objectives

* Analyze overall student academic performance
* Compare average scores across different subjects
* Track performance across different terms
* Analyze student attendance
* Understand student behavior patterns
* Explore student profiles and demographics
* Provide interactive filtering for deeper analysis
* Present complex student data through an easy-to-understand dashboard

## 📈 Key KPIs

The dashboard uses important measures such as:

| KPI                       | Purpose                               |
| ------------------------- | ------------------------------------- |
| Total Students            | Measures the total number of students |
| Average Score             | Shows overall academic performance    |
| Average Attendance        | Measures average student attendance   |
| Average Score per Subject | Compares performance across subjects  |
| Average % Score           | Tracks percentage-based performance   |
| Behavior Count per Type   | Analyzes student behavior             |
| Attendance %              | Shows attendance distribution         |
